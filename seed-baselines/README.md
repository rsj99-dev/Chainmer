# seed-baselines v1.0.0

Scalar, SIMD-free Rust implementations of the six baseline protein seed algorithms used in the
paper *"Using the Chainmer seed algorithm to help proteins find direct orthologs"*
(Chainmer seed benchmark): **k-mer (BLAST+), k-mer (DIAMOND), Minimizer, Syncmer, Strobemer,
SubseqHash2**. Byte-exact compatible with the paper's exporter
(`paper_seed_benchmark/tools/seed_dump.rs`).

## Why Rust, and why no SIMD

- **Cross-platform compatibility**: one Rust codebase with consistent semantics and compilation
  behavior across operating systems and architectures; no C++ undefined behavior, compiler or
  template divergence.
- **Deterministic computation**: x86 CPU vector acceleration is deliberately disabled — pure
  scalar portable code, no SIMD intrinsics (SubseqHash2 is a protein scalar adaptation of the
  official C++ ABCk-orders / forward-backward DP / pivot merge). Key sets and scores are
  byte-reproducible across platforms.
- **Engineering reliability**: compile-time borrow/lifetime checks eliminate data races and
  dangling-pointer class bugs before runtime; long full-database exports run without memory bugs.
- **Experimental consistency**: the Chainmer kernel itself is Rust; these baselines share the same
  hash (splitmix64), cleaning (U→C, non-standard→X), dedup and scoring code as Chainmer/op1,
  minimizing implementation-layer error.

## Algorithms and parameters (paper toolB main protocol)

| Method | CLI | Parameter provenance |
|---|---|---|
| k-mer (BLAST+) | `--method kmer --k 3 --stride 1` | blastp word_size=3 exact words (no T=11 neighborhood words / two-hit) |
| k-mer (DIAMOND) | `--method spaced --masks 111101110111,111011010010111` | DIAMOND v2 default two weight-10 spaced shapes (iedera); union with per-shape salt i×0x9E3779B97F4A7C15; no Murphy10 reduction / double index / frequency filtering |
| Minimizer | `--method minimizer --k 7 --w 10` | minimap2 k=15,w=10 scaled by f=log2(4)/log2(20)≈0.463 |
| Syncmer | `--method syncmer --k 7 --s 5` | Weighted Syncmer (15,10) closed definition scaled; no weighted ordering |
| Strobemer | `--method strobemer --k 7 --w1 9 --w2 32 --t 2` | StrobeMap scaled; fixed-offset simplification (not randstrobe/minstrobe) |
| SubseqHash2 | `--method subseqhash2 --window 25 --subseq 11 --d 5 --repeats 11` | protein scalar adaptation; official SIMD not used |

## Build and usage

```
cargo build --release
target/release/seed-baselines --input in.faa --output keys.tsv --method minimizer --k 7 --w 10
```

Output: `sequence_id<TAB>key_hex32<TAB>pos` (pos = first occurrence; -1 for set-type seeds).
Per-sequence dedup keeps the first position; statistics go to stderr
(`method= seqs= residues= keys= elapsed_ms=`).

## Tests

```
cargo test --release
```

Six regression goldens (`tests/fixtures/mini_*.tsv`, generated by the paper's in-use exporter)
compared byte-for-byte against this crate's CLI, plus unit tests for cleaning and parameter
validation. Full-database HydDB 2012 exports are byte-identical to the paper's in-use
`seed_dump` binary (see the paper's `results/reproduction_check.md`).
